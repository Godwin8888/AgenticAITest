# Lead Magnet Skill

**Source:** https://github.com/openclaudia/openclaudia-skills
**Skill:** lead-magnet

## Purpose
Strategic lead generation and conversion optimization for building email lists and sales funnels.

## Capabilities
- Lead magnet ideation
- Email funnel design
- Landing page optimization
- Lead scoring systems
- Email automation workflows
- CTA optimization
- Conversion tracking
- Audience segmentation

## For SureWinTotoIT
Use to:
- Create lead magnet (e.g., "IT Audit Checklist")
- Optimize enquiry form for conversions
- Build email follow-up sequences
- Improve CTA button copy
- Design post-submission workflow
- Segment prospects by interest
- Track form submission ROI

## Installation
```bash
npx skills add https://github.com/openclaudia/openclaudia-skills --skill lead-magnet
```

## Usage
Ask Claude:
```
/lead-magnet: design a lead magnet strategy for IT services
```
