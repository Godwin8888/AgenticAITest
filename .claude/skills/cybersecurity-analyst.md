# Cybersecurity Analyst Skill

**Source:** https://github.com/rysweet/amplihack
**Skill:** cybersecurity-analyst

## Purpose
Security auditing, vulnerability assessment, and best practices for protecting web applications and infrastructure.

## Capabilities
- Vulnerability scanning & assessment
- OWASP Top 10 analysis
- Security headers audit
- SSL/TLS configuration
- Authentication & authorization review
- Data protection strategies
- Incident response planning
- Compliance (GDPR, CCPA, etc.)

## For SureWinTotoIT
Use to:
- Audit form security (honeypot, validation)
- Review HTTPS/SSL configuration
- Check security headers
- Assess data handling practices
- Verify no sensitive data in code
- Test for XSS/CSRF vulnerabilities
- Review privacy policy compliance
- Security headers optimization

## Installation
```bash
npx skills add https://github.com/rysweet/amplihack --skill cybersecurity-analyst
```

## Usage
Ask Claude:
```
/cybersecurity-analyst: perform security audit on my website
```

*Note: Requires Node.js installed.*
