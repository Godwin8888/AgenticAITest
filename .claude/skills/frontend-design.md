# Frontend Design Skill

**Source:** https://github.com/anthropics/skills
**Skill:** frontend-design

## Purpose
Master modern frontend design practices, component architecture, and UI/UX best practices for building professional web applications.

## Capabilities
- Design system creation
- Component library architecture
- Responsive design patterns
- CSS/Tailwind optimization
- Accessibility (WCAG) compliance
- Performance optimization
- Design tokens management

## For SureWinTotoIT
Use to:
- Refine design system (colors, spacing, typography)
- Create reusable component patterns
- Optimize responsive breakpoints
- Ensure accessibility compliance
- Build design documentation

## Installation
```bash
npx skills add https://github.com/anthropics/skills --skill frontend-design
```

## Usage
Ask Claude:
```
/frontend-design: review my design system and suggest improvements
```

*Note: Requires Node.js installed. Install from https://nodejs.org/*
