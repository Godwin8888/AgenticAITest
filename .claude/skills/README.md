## Installation

**Prerequisite:** Node.js 16+ required
- Download from: https://nodejs.org/ (LTS)
- Install and restart terminal

**Then install all skills:**
```bash
cd "C:\Users\TotoWinner\Documents\AgenticAI\Claude Agentic AI-Tertiary Infotech Academy\Project"

npx skills add https://github.com/anthropics/skills --skill frontend-design
npx skills add https://github.com/nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max
npx skills add https://github.com/coreyhaines31/marketingskills --skill seo-audit
npx skills add https://github.com/openclaudia/openclaudia-skills --skill lead-magnet
npx skills add https://github.com/rysweet/amplihack --skill cybersecurity-analyst
```

## Usage

Once installed, invoke skills in Claude Code:

```bash
/frontend-design: review design system
/ui-ux-pro-max: analyze conversion flow
/seo-audit: audit website SEO
/lead-magnet: design lead generation strategy
/cybersecurity-analyst: security audit
```
