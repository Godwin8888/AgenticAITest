# SEO Audit Skill

**Source:** https://github.com/coreyhaines31/marketingskills
**Skill:** seo-audit

## Purpose
Comprehensive SEO auditing, on-page optimization, technical SEO, and search visibility strategies.

## Capabilities
- On-page SEO optimization
- Technical SEO analysis
- Keyword research & mapping
- Meta tag optimization
- Schema markup implementation
- Site speed optimization
- Mobile SEO audit
- Backlink analysis

## For SureWinTotoIT
Use to:
- Optimize meta descriptions & titles
- Add schema markup for local business
- Improve site speed metrics
- Keywords for "IT services"
- Mobile-first indexing
- Internal linking strategy
- Rich snippets for testimonials

## Installation
```bash
npx skills add https://github.com/coreyhaines31/marketingskills --skill seo-audit
```

## Usage
Ask Claude:
```
/seo-audit: audit my website and provide SEO improvement report
```

*Note: Requires Node.js installed.*
